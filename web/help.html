1. What it does

The remapper sits between a USB mouse or keyboard and your computer. Plug the mouse or keyboard into the board's USB-A port and the board's USB-C port into the computer. Everything passes straight through, except the buttons and keys you remap. It works on any computer, with no software to install.

Any mouse button, wheel direction, wheel tilt, keyboard key, media key or button wired to the board can become a different key or shortcut, a mouse button, a media key, scrolling, pointer movement, typed text, a sequence of steps, a web page or app opening, a foot pedal press, a MIDI note, or a switch to another set of mappings. Pointer movement itself can be sped up, slowed down, flipped, turned into scrolling or switched off.

Mappings are kept in profiles (up to 8 per device, each with up to 8 layers), stored on the board. They survive restarts and power loss, and the page is only needed to change them.

2. Setting up the board

  1. Install CircuitPython 11 for “Adafruit Feather RP2040 with USB Type A Host” from circuitpython.org: hold BOOT, tap RESET, and drag the .uf2 file onto the RPI-RP2 drive that appears.
  2. Copy everything in the download's CIRCUITPY folder to the root of the CIRCUITPY drive: code.py, boot.py and the .mpy files. Don't copy the source folder. No libraries are needed, except one for the optional status display.
  3. Press the board's RESET button once.

To install a newer version later, use Update mode: the drive is otherwise read-only to your computer.

3. Opening the page and connecting

Open remapper.html in desktop Chrome, Edge or Opera (Firefox and Safari can't connect to the board). Opening the file straight from your disk works; if your browser blocks that, serve the folder locally (e.g. python -m http.server, then open http://localhost:8000/remapper.html).

  1. Click Connect in the dark top bar.
  2. The first time, the browser lists serial ports: choose the board. From then on the page connects by itself when it opens and whenever the board is plugged in. (Some browsers forget the board for pages opened from a file; then click Connect once per visit.) Shift-click Connect to choose again from every serial port.
  3. The pill turns green and shows the device on the USB-A port, e.g. 8-button mouse · connected.

You can edit, import and export mappings without a board; you only need a connection to apply them. After you click Disconnect, the page waits for you to click Connect again. The board can only be open in one tab or program at a time.

Sometimes two ports are listed (in Update mode, or after starting the board with the recovery jumper). Either one works.

“No answer from the remapper firmware”

The firmware isn't running. Check the debug log for errors, make sure all the files are on the drive (boot.py must be named exactly that, not boot.py.txt or boot (1).py), and press RESET.

Reordering and removing inputs

5. Remapping an input

  1. Select the input on the picture or in the list.
  2. In the inspector, choose an action group with the tab bar (Button, Mouse, Control, Multi, Basic), then the action. A short description of the group, then of the chosen action, shows under the buttons.
  3. Set the action up. The input is remapped as soon as you choose something: a key, a media key, a profile, a setting. Choosing a group or an action on its own changes nothing. Off, Unlatch, Cycle and Macro have a button to click; Text, Web and App remap the input as soon as you type.
  4. Click Apply to send your changes to the board and save them.

The inspector opens on the group of the input's current action; a dot marks that group while you look at another one.

GroupWhat it's for
ButtonMakes the input act like a single button: a keyboard key or shortcut, a media key, a mouse button, or a foot pedal. It's held as long as you hold the input, or until you press it again if set to Latched.
MouseUses the input to scroll, or to move the pointer by itself. Configure changes how your mouse's own movement behaves, such as slower, one axis only, or scrolling instead.
ControlChanges how the remapper behaves rather than sending anything: switch profiles, turn on a layer, or release everything latched. MIDI is here too, for sending notes to music software.
MultiDoes several things from one press. It can type text, play a macro, step through a cycle of actions, or open a web page or app.
BasicDefault leaves the input doing what it normally does, which is also how you undo a mapping. Off disables it completely.

Undoing a mapping

Choose Default (Basic group), or click Restore default at the bottom of the inspector. On a layer, the button is Use Base mapping and returns the input to its Base layer mapping. To drop every change you haven't applied, use Reload from the board in the menu next to Apply.

When: While held or Latched

Keys, Mouse, Media, Pedal, MIDI notes and controllers, Pointer and Configure have a When setting at the top:

  • While held: the action is on while you hold the input.
  • Latched (toggle): one press turns it on and it stays on after you let go; the next press turns it off. For example, a side button as a latched Shift, a latched left button for dragging without holding, or a latched pedal.

Everything latched is let go when you press an Unlatch input, switch profile, apply mappings, unplug the device or restart the board. Switching layer keeps latches. The status display shows L before the profile name while anything is latched.

Label and options

Below each action's settings:

  • Label (optional): a name of up to 24 characters shown in the list instead of the action, e.g. “Close tab”.
  • Repeat while held (Keys, Mouse, Media): fires the action again every 50 ms until you let go.
  • Also send the original click: does the new action and what the input normally does, e.g. the right button still right-clicks and also presses a pedal.
  • Haptic pulse: also gives a pulse on a Logitech mouse with haptics (e.g. MX Master 4) when the input is pressed. Try plays it. Shown while such a mouse is attached, or always if you turn that on under Settings › Feedback › Mouse haptics. To make an input only pulse, use this with the action Off.

Choosing another action keeps the label and options.

Example: thumb buttons as copy and paste. Select Thumb back › Button › Keys › Record new shortcut › press Ctrl+C. Select Thumb forward and record Ctrl+V. Click Apply. (On a Mac use Cmd, which records as GUI.)

6. The actions

An action whose output is turned off in What your computer sees isn't offered (e.g. no Pedal without the foot pedal). A mapping that needs an output that's off is marked ⚠ and does nothing until you turn the output back on.

Button group

ActionHow to use it
KeysSends a keyboard key or shortcut, such as A, Enter or Ctrl+C. Click Record new shortcut and press it; pressing only modifiers and letting go records them on their own (e.g. a button that holds Shift). For shortcuts your computer catches first (such as Ctrl+Alt+Del), open Choose keys by hand, tick the modifiers and pick a key.
MediaSends a media key: volume, mute, play/pause, next track, or a launcher key such as Calculator or Browser home.
MouseSends a mouse button click: left, right, middle, back, forward or buttons 6–8.
PedalPresses the left, center or right pedal (or left + right) of the board's foot pedal.

Recording tip: Record reads the key your browser receives. A key pressed on a keyboard that goes through the board, and is already remapped, records as its remapped key. When in doubt, record with your computer's own keyboard or choose keys by hand.

Mouse group

ActionHow to use it
ScrollScrolls in the chosen Direction (up, down, left or right) on each press. Steps per press sets how far, from ×1 (one notch of a scroll wheel) to ×10. Holding the input keeps scrolling.
PointerMoves the pointer by itself:
  • Direction: one of eight arrows.
  • On each press: how far it moves at once, about in pixels (0 = none). A wheel notch counts as a press: map Wheel up to ↑ and Wheel down to ↓ to move the pointer with the wheel.
  • While held: Only the step, or Keeps moving at a Speed (counts per second), reaching full speed over the Speeds up over time, so short holds aim finely and long holds cross the screen.
Several held at once add up, so four buttons mapped to the four arrows work like a joystick. Latched, the pointer keeps drifting until you press the button again.
ConfigureChanges how your mouse's own movement behaves while it's on:
  • Pointer: As the profile, Moves (moves even when the profile's movement is Off), or Scrolls.
  • Speed: Unchanged, or Change to a percentage of the profile's speed (10–400 %), e.g. 25 % for precise aiming. It applies to Pointer movement too.
  • Axes: Normal, Flipped or Off for left / right and up / down, and Swap X and Y.
If several are on at once, the last one pressed counts; letting go of it brings back the one before.

Example: pointer locked, with one button for left / right only. Set the profile's Movement to Off. Map a button to Configure with When Latched, Pointer Moves and up / down Off. Press it and the pointer moves left and right only; press it again and it's locked.

Control group

ActionHow to use it
ProfileSwitches to the next or previous profile, or to one you choose, or uses one only while held. See switching profiles.
LayerSwitches to the next or previous layer of the profile, or to one you choose, or uses one only while held. See layers.
UnlatchReleases everything that is currently latched: keys, buttons, pedals, MIDI notes and movement changes.
MIDISends a MIDI message on a channel (1–16) to music software. Needs MIDI turned on in What your computer sees.
  • Note: plays while the input is held, at the chosen velocity (60 = middle C).
  • Controller (CC): set to the chosen value while held, back to 0 on release (e.g. 64 = sustain, 7 = volume).
  • Program change: selects program 1–128.

Multi group

ActionHow to use it
TextTypes a phrase or block of text (up to 2,000 characters) on each press. New lines are typed as Enter. It types as on a US keyboard layout: with another layout some characters come out differently, and characters a US keyboard can't type (accents, emoji) are shown in red and left out. Typing takes about 12 ms per character; pressing the button again while it types does nothing.
CycleSteps through a list of actions, one per press, then starts again. Click Make a cycle: the current action becomes step 1. Click a step to set it up with the same tabs as any input; ↑ ↓ reorder, ✕ removes, + Add step adds (up to 8). Back to step 1 after … s idle restarts the cycle after a pause (0 = never). Profile and layer switches can't be steps.
MacroPlays a list of steps in order on one press. Click Make a macro, then edit the steps as in a cycle (up to 16), plus Wait steps (0.01 to 10 s) to give the computer time, e.g. for a window to open. Each step is a short tap; a text step is typed in full before the next. The macro runs to the end even if you let go, and pressing it again while it runs does nothing. Profile and layer switches, cycles and other macros can't be steps.
WebOpens a web page. Type the Address (e.g. example.com/docs; https:// is added if needed) and choose how to open it:
  • Win+R (Windows): the Run box, in your default browser.
  • Spotlight (Mac).
  • Ctrl+T / ⌘T: a new tab in the browser that's in front.
  • Browser (Windows, Linux): the Browser home key opens your browser, then the address goes in its address bar. Needs Media keys on in What your computer sees. If your browser starts slowly, the first press may only open it.
AppOpens an application by name, e.g. Calculator. Choose Start menu (Windows), Spotlight (Mac) or Win+R (Windows; only programs it knows by name, such as notepad or chrome). The first match opens, so use the app's full name.

Web and App type their address or name like Text, so only plain US-keyboard characters can be used. If nothing opens or the wrong thing does, the shortcut may be turned off on your computer, or it needs more time: a Macro with a longer Wait does the same job.

7. Movement, scroll wheel and tilt

Movement

Select the Movement row to set how the profile's pointer movement works:

  • Move pointer (normal), Scroll (moving the mouse scrolls), or Off (buttons still work).
  • Speed: 10 % to 400 %.
  • Invert X, Invert Y and Swap X and Y, e.g. for a trackball held sideways.

To change movement only while a button is held or latched, use the Configure action.

Scroll wheel

Wheel up and Wheel down can be remapped like buttons: each notch is one press. To reverse scrolling, map Wheel up to Scroll down and Wheel down to Scroll up.

Wheel tilt

When a tilt input is selected, Tilt acts like a held button sets what a remapped tilt does:

  • Ticked (default): holding the wheel tilted holds the action once, like holding a button. It's released when the tilt stops for the Release after … ms time (default 300 ms). If the action flickers while you hold the tilt, raise this time; if it lingers after you let go, lower it.
  • Unticked: the action repeats for as long as the wheel is tilted.

These settings belong to the profile. Unmapped tilt scrolls sideways as usual.

8. The device picture and testing

The picture shows a numbered marker for each input; click one to select it. The page picks an outline to suit the device: a standard mouse, a mouse with a side grid of buttons, a trackball, a vertical mouse, or a keypad / keyboard. A keyboard with more than 24 keys is drawn as a wide grid.

Arrange

Click Arrange in the picture's header to make the picture match your device. The header then holds:

  • the shape menu;
  • Photo ▾: Use a photo… puts a photo of your own device behind the markers (it stays on your computer), and Remove photo;
  • ↺: puts every marker back where the shape places it;
  • ?: shows the tip again;
  • Done.

Drag a marker to where that button really is, or select it and use the arrow keys (with Shift to move further). Inputs that aren't on the picture appear as numbered chips in the strip below it: drag a chip onto the picture (or select it and press Enter) to place it, and drag a marker onto the strip (or press Delete) to take it off. The arrangement is saved for each device in this browser, and included in Export.

Testing without sending

Move the pointer onto the device picture: the card turns blue and the strip reads Testing — nothing is sent. While the pointer is on the picture, presses on the device plugged into the board aren't sent to the computer; the strip shows what they would do instead, e.g. Thumb back → Type “Best regards,” (not sent). Move off the picture to go back to normal.

  • Pointer movement always works normally, so you can always move off the picture.
  • Profile and layer buttons still switch, so you can hold a layer button and see what the other buttons do on that layer. Cycles move on to their next step without sending anything.
  • Testing pauses while the pointer is on a marker, so you can click it, and is off while you arrange the picture.
  • Your computer's own keyboard and touchpad aren't affected.
  • If the page closes or loses the board while testing, the board goes back to normal within about 1.5 seconds.

9. Profiles and layers

A profile is a complete set of mappings, with its own movement and tilt settings and LED color. Each device can have up to 8, e.g. one for work and one for a game.

  • Click a profile in the Profiles sidebar to edit it. The one the board is using says Active on device (Held now while a hold button is held).
  • Click the profile's name to rename it. + New profile adds an empty one, Duplicate copies the one you're editing, Delete removes it, and Reset profile removes all its mappings.
  • Make active makes the board use the profile you're editing.
  • LED color sets the color of the board's light while the profile is in use. Pick a quick color or Custom color…. The same window has the light's Brightness, shared by all profiles. The board's light shows the color while you pick, so you can see how it looks.

Adding, copying, deleting and renaming profiles and layers is saved to the board by itself. Changes to what inputs do need Apply.

Profiles don't change by themselves when you switch programs on your computer: use a profile button.

Switching profiles with a button

Map an input to Profile (Control group) and choose Next profile, Previous profile (both wrap around) or a specific profile. Put the switch button in every profile, so you can always switch on or back.

  • The new profile applies from the next press on. Held keys and buttons are released, except latched pedals.
  • The board remembers the active profile, even after a restart.

Using a profile while a button is held

In Profile, choose a profile under Hold (Use … while held). While the button is held, that profile is active; let go and you're back where you were, like a Shift key for your whole mapping.

  • The hold button keeps working to switch back, whatever the held profile maps it to.
  • To reach a third profile, map a second hold button in the held profile. Releasing either goes back step by step.
  • A normal switch pressed during a hold takes over, and letting go of the hold button no longer switches back.
  • A held profile isn't remembered: after a restart, or if the device is unplugged while holding, the board is on your normal profile.

Layers

Each profile can have up to 8 layers: Base plus up to 7 more. A layer changes only the inputs you remap on it; every other input does what it does on Base. Use a layer when a few buttons should do something else for a moment (e.g. “hold the thumb button for editing keys”), and a profile for a completely different setup.

  • The Layers bar above the list shows the profile's layers; click one to edit it. + Add layer adds one; any layer except Base can be renamed and deleted. A green dot marks the layer the board is using.
  • On a layer, inputs you haven't remapped show their Base mapping in gray italics. Remap one to change it on that layer only.
  • To move between layers, map an input to Layer: Next layer, Previous layer, a specific layer, or a layer only while held. Put the layer button on Base: every layer uses it unless you remap it there.
  • Movement, tilt and LED color belong to the profile and are the same on every layer.
  • Switching profile, and restarting the board, start on the Base layer. Apply keeps the layer you're on.

The board's light

LightMeaning

10. Profiles for each device

Each mouse or keyboard has its own profiles. When you plug in a different device, the board switches to its profiles and the page shows them. The box at the top of the Profiles sidebar says whose profiles you're editing.

  • A device used for the first time starts with one empty profile, so everything works as normal.
  • Copy profiles from… (in that box) loads another device's profiles; click Apply to keep them.
  • Saved on the board lists every device with saved profiles, with a Delete button for each.
  • Changes made before any device is plugged in go to the first device plugged in (click Apply to save them).
  • Mice paired to the same receiver share its profiles. With two devices plugged in at once, the first one's profiles are used.
  • Edits you haven't applied are dropped when a different device is plugged in (unplugging and replugging the same device keeps them). If the page had unapplied edits when it connected, a blue bar offers Put my edits back.
  • Board settings (light, display, haptics, names) are shared by all devices.

11. Mice whose buttons send keys

Some mice with many buttons send some of them as keyboard keys; a Razer Naga's 12-button side plate, for example, types 1…0, - and =. These are listed as Keys sent by the mouse, separately from Keyboard keys, so remapping the mouse's 1 doesn't change the 1 on a keyboard plugged in at the same time. Unmapped, they keep typing their key. Press each side button once to add it to the list.

  • Button assignments saved in the mouse with its own software (e.g. Razer Synapse) still apply.
  • For a wireless mouse, use its receiver: a mouse charging over its cable from the board can draw more power than the port gives.

12. Buttons on the board

You can add your own buttons to the board and remap them like any other input. The board's BOOT button works too: until you map it to something else, pressing it opens the Rad USB Remapper page in your browser, using Win+R (Windows).

  • Wiring: connect a button between a free pin and GND; no resistor is needed. Free pins: A0–A3, D24, D25, SCK, MO, MI, RX, TX, D4, D6, D9, D10, D11, D12. Leave SDA/SCL (status display), D5 (recovery jumper) and D13 alone.
  • A button appears in the list under Buttons on the board the first time you press it, named after its pin (e.g. Board button D9). Until you map it, it does nothing (except BOOT, which opens this page).
  • Board-button mappings are part of each device's profiles, so they can do different things with different devices. BOOT's page opening also works with no device plugged in.
  • Holding BOOT while the board starts opens the bootloader instead; tap RESET to start normally.
  • To use the pins for something else, turn off Settings › Board › Advanced: buttons on the board's pins.

13. Foot pedal

The board can act as a three-pedal USB transcription foot pedal, so any button or key can press the left, center or right pedal in programs that support USB foot pedals.

  1. In Settings › Board › What your computer sees, tick Foot pedal and click Reboot now. With Keyboard and Mouse also ticked, your mouse and keyboard keep working; with Foot pedal on its own, the board is only a pedal.
  2. Select an input, choose Button › Pedal, pick the pedal, and set When:
    • While held: the pedal is down while you hold the button.
    • Latched (toggle): one press puts the pedal down and it stays down; the next press lifts it.
    Click Apply.
  3. In your transcription program, choose its USB foot pedal option, as you would for a real pedal, and use its test screen to check the pedals.

Example: a side button as Center pedal, Latched starts and stops playback with single clicks; two more buttons as Left and Right pedal, While held rewind and fast-forward while held. A pedal is down while any button holds it or it's latched.

Latched pedals are lifted when you press an Unlatch input, apply mappings, unplug the device or restart the board. They stay down when you switch profile.

If your program doesn't find the pedal

Try these in Settings › Board, one at a time, rebooting after each:

  • Turn Media keys off.
  • Set Mouse type to Standard.
  • Give the board a different Device name.
  • Tick Foot pedal on its own.

Close other programs that might be using the pedal. On Windows, removing the board once in Device Manager after a change can help. To go back to normal, untick Foot pedal, tick Keyboard, Mouse and Media keys, and reboot. If you can't reach the page, use the recovery jumper.

16. Settings

The gear ⚙ opens Settings. Close it with Close, a click outside or Esc. Settings that don't apply right now are hidden.

  • Board: What your computer sees, the CIRCUITPY drive, Update mode, buttons on the board's pins, and Reboot board. Most of these take effect after a restart.
  • Feedback: LED color balance, the status display, mouse haptics and mouse lighting.
  • Troubleshooting: the debug log and its tools.

LED color balance

Adjusts how profile colors look on the board's light: Red / Green / Blue balance and gamma correction. (Brightness is in each profile's LED color window.) Changes show on the light while you drag. To tune the balance, give a profile the color white and lower whichever channel the light looks tinted toward. Reset to recommended puts everything back. At low brightness, similar colors can look the same and very dark colors may not light at all.

Status display

Plug Adafruit's 0.91" SSD1306 128x32 OLED into the board's STEMMA QT connector. It shows the device's name and battery on the top line, and the active profile and layer on the bottom line (with L in front while anything is latched).

  • Setup: from the CircuitPython library bundle for your CircuitPython version, copy adafruit_displayio_ssd1306.mpy into CIRCUITPY/lib (using Update mode).
  • You can plug the display in while the board is running; it's found within 10 seconds.
  • Settings › Feedback › Status display shows whether it was found, and has Upside down (180°) for a display mounted the other way round.

Mouse haptics

For Logitech mice with a haptic motor, such as the MX Master 4. Shown while such a mouse is attached:

  • Pulse when the profile or layer changes: choose the pulse, or No pulse.
  • A different pulse for each profile and layer, so you can feel which one you're on.
  • Haptics on and Strength, stored in the mouse.
  • Try buttons play each pulse.
  • Always show the Haptic pulse option on mappings, to set up pulses while the mouse isn't attached.

A sleeping mouse can't pulse; move it to wake it.

Mouse lighting

Match the mouse's own lighting to the profile color sets the RGB lighting of a Logitech or Razer mouse to the active profile's color, so the mouse shows which profile you're on. Brightness sets how bright.

  • The color is set when the mouse is plugged in, when you switch profile, and when you use the mouse again after a pause.
  • Close Logitech G HUB, Razer Synapse or other lighting software, or it may change the lighting back.
  • Turn this off if you notice stuttering.
  • Wireless mice dim their lights to save battery, and colors may look a little different from the board's light.
  • Logitech mice go back to their own lighting when you turn the option off or unplug them. Some Razer mice keep the color until you change it with Razer's software.

17. Device panel, names and battery

Once connected, click the connection pill (or the battery) for the device panel: what's plugged into the USB-A port, its name and USB ID, its battery, the firmware version, Show this device as, Get device info, Read battery and Disconnect.

  • Show this device as gives the device your own name, e.g. the keyboard behind a receiver that only reports its own name. It's used on the page and the status display. Clear goes back to the automatic name.
  • Get device info writes the board's full details to the debug log: the firmware, what the device reports, the profiles, memory and more. Useful for problem reports.

Battery level

For wireless mice and keyboards that report it, the battery level shows in the top bar (with a lightning bolt while charging, amber at 30 % or less, red at 15 % or less) and in the device panel. It's read a few seconds after the device is plugged in and then every few minutes. It works with Razer wireless mice, Logitech devices on a Bolt, Unifying or Lightspeed receiver, and devices that report their battery in the standard way. Keychron keyboards on the Keychron Link dongle don't report it.

  • Some Logitech devices only give a rough level; the page then shows “about …”.
  • A sleeping mouse can't answer: the last level stays, dimmed and marked last known, until the mouse is used again.
  • If nothing works, the panel says battery not reported. Read battery checks right away and writes the details to the log.

18. The CIRCUITPY drive and updating

The board saves your profiles on its CIRCUITPY drive, so your computer can only read it. Settings › Board › CIRCUITPY drive sets whether the computer sees it: Shown (read-only, the default) or Hidden. The change takes effect after a restart, and the page works either way.

Update mode: installing a new version

  1. Settings › Board › Update mode…. The board restarts with the drive open to your computer, and an orange bar on the page says so.
  2. Copy the new files onto CIRCUITPY and wait for the copy to finish. Don't restart the board before that.
  3. Click Restart board on the orange bar (or press RESET).

Copy the page (remapper.html and help.html) from the same download as the board files: the log warns when they don't match. In Update mode the remapping works, but profile changes can't be saved.

If you can't reach the page

  • Recovery jumper: connect pin D5 to GND and press RESET. The board starts with keyboard, mouse and media keys, the default names and the drive open to your computer, so you can connect and fix the settings. Remove the jumper afterwards.
  • Safe mode: press RESET, then press it again while the light blinks yellow. The drive appears but the remapper doesn't run; press RESET to leave.

Jerky or stuttering movement

  • Turn off Verbose in the debug log.
  • Turn off Mouse lighting.
  • Close the page, or click Disconnect, when you aren't using it.

To check, click Measure smoothness in Settings › Troubleshooting and use the mouse normally for 10 seconds. The log then reports how smoothly the board kept up: mouse reports sent to the computer should be close to 125 a second while you move the mouse, with few that waited. Copy the log if you report a problem.

USB scan

USB scan lists everything on the USB-A port in the debug log:

  • “0 device(s)”: the device didn't answer. Unplug and replug it, or try it through a powered USB hub.
  • Listed but “not attached”: the board couldn't use it. It retries for a few seconds after plugging in.
  • “understood: nothing usable”: the device isn't a standard mouse or keyboard.

If a device still doesn't work, copy the log after a scan and include it in a problem report.
